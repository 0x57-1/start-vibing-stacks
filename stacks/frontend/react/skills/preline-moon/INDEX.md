# Preline moon — index is on the live corpus

This package ships a **pointer** (`SKILL.md`), not the example dump.

1. Resolve `$CORPUS` — **`$HOME/.claude/skills/preline-moon` first**, then a
   project capture. See `SKILL.md`. A folder with only this file + `SKILL.md`
   is not a corpus.
2. Open `$CORPUS/INDEX.md` (components), `$CORPUS/TEMPLATES.md` (pages),
   `$CORPUS/PRO-BLOCKS.md` (paste-ready fragments).

If neither tree has `INDEX.md` + (`examples/` or `data/index.json`), there
is no offline capture. Do not invent markup. Do not fetch preline.co.
