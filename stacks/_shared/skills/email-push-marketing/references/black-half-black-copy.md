# Black / half-black email copy (conversion first)

Load with skill `email-push-marketing` when adapting a converting reference or
writing owned-list / push in finance, adult, betting, health, make-money.

**Law:** CTR is the job. Never soften, moralize, or change the sense of a
converting email without a **hard-limit hit** on a specific sentence. “Safer
editorial” that kills the hook is a defect.

Hard limits still win (memory `email-push-marketing-authorization`): no phishing,
no official-sender bank/brand, no official bank logo on a fake receipt, no
spoofed `From`, no fabricated **personal** approval/limit/protocol as fact.

---

## Two registers

| | **Black** | **Half-black** |
|---|---|---|
| Job | Max open + click. Same heat as the reference. | Same heat, one degree of distance on the **verb**. |
| Voice | You / you. Name. Money. Threat of missing it. Unfinished sentence. | You / you. Money. “está liberando / vê se entra / tem gente vendo”. |
| When | User asks black, or the reference is already black and no hard-limit line. | One line would be a **personal bank fact** (“seu X foi aprovado com R$Y”). |
| Not | Dry “conheça as vantagens”. Disclaimer-first. Rate-table rewrite. | Flattening the rest of the email after swapping one verb. |

Default when adapting a hot reference: **stay as black as the source**. Drop to
half-black **only** on the offending sentence. Keep product nickname, cifra,
2nd person, layout, CTA.

---

## Never do this (CTR murder)

| Soften | Why it loses |
|---|---|
| “Conheça o cartão Nubank e suas vantagens” | Curiosity dead. No you, no money, no clock. |
| Drop Ultravioleta / the cifra because `?s=` is thin | Keyword was the hook. Destination = note after ship. |
| Add a disclaimer the template did not use | Cools the first screen. Footer already exists. |
| Rewrite the card into a rate table | Different offer. Different click. |
| Restyle purple → “brand” without being asked | Breaks pattern-match with the reference. |
| Lecture about Gmail / overlap / “two lists same number” | Not the task. One hard-limit line max. |

---

## Keep from the reference (always)

1. **Emotional payload** — envy, fear of missing, confrontation, unfinished loop.
2. **Specifics** — product slang, cifra, prazo, nome do cartão. Vague = dead.
3. **2nd person + merge** — `[Name]` / `{{ name }}`. “teste, seu cartão” from a
   botched test send → `[Name]`, not “olá leitor”.
4. **Rhythm** — short lines, one idea per block, CTA as the only exit.
5. **Subject ↔ preview ↔ first line** — same promise. No bait-and-switch
   *into a weaker promise*.

---

## Subject / preview

**Black** (user’s From, user’s list):

| Pattern | Example |
|---|---|
| Unfinished + money | `[Name], os R$8.550 do roxo…` |
| Confrontation | `[Name], você ainda não viu isso` |
| Clock | `[Name], isso some hoje` |
| Direct steal of reference heat | Same structure as Plusdin/Mengão; only From/brand change |

**Half-black** (only if the black subject is a personal fact):

| Black (refuse as fact) | Half-black (ship) |
|---|---|
| `seu Ultravioleta foi aprovado` | `[Name], Ultravioleta liberando até R$8.550` |
| `Sua aprovação Nubank está pronta` | `[Name], tem gente vendo limite alto no roxo` |
| `Comprovante da sua última transação` | `[Name], esse valor não pode ficar parado` |

Preview: complete the curiosity. Do not preview “newsletter / leia no site”.

## Body openers

**Black**

```
[Name],

abre isso.

o roxo está com R$8.550 na mesa.
se não for você, outra pessoa clica.
```

**Half-black** (same heat, verb distance)

```
[Name],

o Ultravioleta está liberando até R$8.550.

vê se o seu perfil entra — o clique é o filtro.
```

Do **not** open with “hoje vamos falar sobre crédito consciente”.

## CTA

| Black | Half-black | Dead |
|---|---|---|
| `ABRE AGORA` / `VER MEU LIMITE` / `QUERO ISSO` | `VER SE EU ENTRO` / `CONFERIR O ROXO` | `Saiba mais` / `Leia o artigo` / `Conheça` |

Link = user’s tracking (`?s=` / UTM). Never competitor `upn=` / open pixel.

---

## Push (same law)

| Black | Half-black |
|---|---|
| `[Name] o roxo tá com R$8.550` | `[Name] Ultravioleta liberando até R$8.550` |
| Body: `abre antes que suma` | Body: `vê se o perfil entra` |

Forbidden: fake OS/bank push (“Pix recebido” as if from the bank app).

---

## Adapt checklist (reference → user list)

1. Strip their open pixel, click `upn`, unsubscribe, MIME crumbs, their legal.
2. Swap From, footer, address, links → user ESP.
3. Keep palette, card, pill CTA, signature rhythm.
4. Keep hook energy. If one line is a personal bank fact → half-black **that
   line only** (table in the parent skill).
5. Official bank/card **logo as header identity** on a fake receipt → user logo.
   Rest of the email stays hot.
6. Ship. Then one line on thin `?s=` / 404 if needed. Do not rewrite copy for it.
